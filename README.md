1. Project Overview

This project focuses on creating engaging and authentic User-Generated Content (UGC) style advertisements using Artificial Intelligence and Prompt Engineering.

The objective is to develop attractive promotional content for social media platforms such as Instagram Reels, Instagram Ads and YouTube Shorts.

2. Business Details
	•	Business Name: Alpha Beauty Unisex Salon
	•	Business Type: Beauty and Grooming
	•	Location: Shivamogga, Karnataka, India
	•	Target Audience: Men and Women

3. Tools Used
	•	ChatGPT – AI-powered content generation
	•	GitHub – Project documentation and version control
	•	Markdown – Documentation formatting

4. Project Objectives
	•	Create engaging UGC-style advertisement hooks.
	•	Develop short promotional video scripts.
	•	Generate attractive Call-to-Action (CTA) lines.
	•	Create social media captions.
	•	Develop advertisements in different writing tones.
	•	Apply effective prompt engineering techniques.

5. Tasks Completed

1. UGC Ad Hooks

Created 10 attention-grabbing hooks for social media advertisements.

2. UGC Ad Scripts

Created 5 short video advertisement scripts covering:
	•	Hair Care
	•	Skin Care
	•	Grooming
	•	Makeup
	•	Bridal Services

3. UGC Ad CTAs

Created 15 attractive Call-to-Action lines for appointment bookings and customer enquiries.

4. Social Media Captions

Generated 10 promotional captions with relevant hashtags and CTAs.

5. Tone Variations

Created four advertisement versions:
	•	Professional Tone
	•	Friendly Tone
	•	Luxury Tone
	•	Simple Tone

6. Content Framework

The advertisement scripts follow:

Problem → Solution → Call to Action (CTA)

This framework helps create clear, relatable and engaging promotional content.

7. Target Platforms
	•	Instagram Reels
	•	Instagram Ads
	•	YouTube Shorts

8. Project Files
	•	ugc-ad-content-pack.md – Contains project details, prompts and generated outputs.

9. Expected Outcome

To demonstrate how AI and structured prompt engineering can help local businesses create authentic, engaging and professional social media advertisements.

10. Conclusion

This project demonstrates the practical use of Artificial Intelligence and Prompt Engineering in UGC-style advertising and social media marketing.
